# Week 1: Introduction to Programming and Environment Setup

## Overview
This week focuses on setting up the development environment, understanding basic programming concepts, and writing your first lines of code.

## Learning Objectives
- Install and configure the code editor (VS Code).
- Understand the basics of version control with Git.
- Learn fundamental syntax and data types.
- Execute basic scripts in the terminal.

## Tasks
1. [ ] Install Python/Node.js.
2. [ ] Configure Git and GitHub.
3. [ ] Create a "Hello World" project.
4. [ ] Complete the introductory exercises.
